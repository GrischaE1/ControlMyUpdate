About this generator

      

        
A self-contained, offline rebuild of the Control My Update Profile Generator. Everything runs in your browser — no data leaves this page. Open the file directly (file://) or host it anywhere.

        
Control My Update tab writes the settings the CMU engine v3.0 actually reads from HKLM:\SOFTWARE\ControlMyUpdate\Settings. Three delivery formats are produced:

        
    
          
  • PowerShell (.ps1) — universal: Intune/WS1 scripts, ConfigMgr, RMM, or run manually as SYSTEM.
    • 
          
  • Workspace ONE (SyncML) — a Custom Settings profile using the com.airwatch.winrt.powershellcommand CSP.
    • 
          
  • Registry (.reg) — quick manual apply / lab testing.
    • 
        

        
What changed vs. the old WPF GUI

        
    
          
  • Added the v2.3 reboot model the old GUI never wrote: NoReboot, ForceReboot, RebootGracePeriod, BlockRebootWithUser, ForceRebootwithNoUser, MWAutomaticReboot. RebootGracePeriod in particular is read by the engine but was previously impossible to set from the GUI.
    • 
          
  • Removed settings the engine no longer consumes: NoMWAutomaticReboot, MWBlockRebootWithUser, MWForceRebootOnlyDuringMW, NotifyEnduserOutsideOfMW, and the legacy *AutoRebootInterval values — so the output matches the engine exactly.
    • 
          
  • Windows Update & Delivery Optimization tabs emit OMA-URI SyncML for Custom Settings profiles (Windows 10 20H2+ / Windows 11).
    • 
        

        
Not affiliated output — review generated profiles before deploying to production fleets.
